01.

About

Over five-plus years as a .NET developer I've moved from shipping features to owning architecture. Today I lead backend architecture, API development, and database performance tuning for a multi-module enterprise ERP platform spanning finance, inventory, procurement, and HR — designing each module with Clean Architecture and SOLID principles so the system stays extensible instead of ossifying after its first release.

My work sits where three things meet: architecture that survives its second year, APIs that stay fast under real load, and SQL Server schemas that don't collapse when the data volume arrives. That means modular monolith and Clean Architecture design, CQRS, and DDD building blocks applied to real production systems — not to side projects.

I've also spent a lot of time on the unglamorous half of enterprise work: modernizing legacy APIs that can't be rewritten, integrating Oracle systems into .NET applications, keeping POS, accounting, and inventory platforms in real-time sync, and wiring a customer e-invoicing platform into a national tax-compliance system in Saudi Arabia. Systems with regulators attached teach you to care about correctness in a way greenfield work doesn't.

I'm currently open to Senior Backend .NET and .NET Architect roles — on-site, hybrid, or remote.
